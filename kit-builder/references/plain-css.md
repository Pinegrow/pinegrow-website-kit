# Plain CSS kits

Not in this version of the skill yet. Tell the user, and offer a Tailwind CSS kit instead, or wait for the version
with plain CSS support.

What it will cover: Pinegrow's Design panel for plain HTML projects defines any color names as CSS variables and two
fonts (text and headings), and writes them to `css/theme.css`, which it generates and locks. The kit's own classes
live in a project stylesheet and use those variables, because component styles are a Tailwind CSS feature.
