Not in this version of the skill yet. Pinegrow can export a kit as a WordPress block theme (every block becomes a
WordPress block), and a later version of this skill will cover it and check it.

For now:

- Build the kit as usual. Keep every block self-contained (its own background, no reliance on the page around it), so
